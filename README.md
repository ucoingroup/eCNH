## 九、背景知识

### 仙女座星系

> 仙女座星系（Andromeda Galaxy，编号 M31）是我们银河系最近的巨大邻居，也是人类肉眼可见的最遥远天体之一。
>
> 仙女座星系不仅是天文学研究的里程碑，也是未来银河系命运的关键角色。它的庞大、接近与结构复杂性，使其成为星际文明设定中最常被引用的真实星系之一。

### 离岸华夏币（CNH）

> 离岸华夏币（CNH）与美元（USD）的汇率是指在中国大陆以外的市场上，华夏币与美元之间的兑换比率。离岸华夏币是指在境外交易的华夏币，通常通过香港、新加坡等国际金融中心进行流通，而岸内华夏币（CNY）则指在中国境内使用的华夏币。
>
> 离岸华夏币汇率通常会受到市场供求关系、国际经济形势、央行政策等多种因素的影响，因此与岸内华夏币的汇率可能有所不同。
